# security-awareness-training

# 資安教育訓練

本專案收錄資安教育訓練教材與互動示範，供同仁學習辨識常見威脅，並建立安全使用資訊系統的習慣。

## 目前教材

### 釣魚郵件與社交工程示範

檔案：`phishing-training-demo.html`

透過模擬郵件、假登入頁及輸入資料展示，說明攻擊者如何利用帳號停用、限時處理等話術，誘導使用者提供帳號密碼。

目前先上傳 HTML，測試頁面顯示及操作效果，尚未完成正式發布前的安全調整。

## 使用注意事項

- 本教材僅供教育示範，不是真實登入服務。
- 僅使用虛構資料，請勿輸入真實帳號、密碼、個資或其他機敏資訊。
- 目前版本會將輸入內容寫入瀏覽器 Cookie，測試後請按「重新開始」清除示範 Cookie。
- Cookie 可能隨後續符合條件的網站請求送出，因此不可將本版本視為安全的帳密收集工具。
- 如誤填真實密碼，請清除示範 Cookie，並立即更換該密碼。
- 正式提供同仁使用前，將調整為不接受真實帳密、不儲存敏感資料的示範方式。
